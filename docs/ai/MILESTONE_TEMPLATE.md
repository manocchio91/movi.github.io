# Template milestone

```text
Titolo

[Nome breve e univoco]

Obiettivo

[Risultato osservabile da ottenere]

Contesto

[Vincoli e stato di partenza strettamente necessari]

Implementare

- [Requisito funzionale o tecnico verificabile]
- [File/area interessata, se nota]
- [Casi negativi, autorizzazioni o migrazioni richieste]

Aggiornare

- [Test]
- [Documentazione]
- [Stato progetto, solo se necessario]

Criteri di accettazione

- [Comportamento atteso misurabile]
- [Condizioni limite]

Fuori scope

- [Funzionalità o area da non modificare]

Verifiche richieste

- [Comando automatico e risultato atteso]
- [Browser QA applicabile]

Git

- Commit: [tipo: descrizione]
- Push sul branch corrente: [sì/no]
- Merge: no
- Tag: no

Report finale

- file modificati;
- verifiche eseguite;
- Browser QA;
- commit;
- push;
- working tree;
- debiti residui.
```

Ogni requisito deve appartenere alla stessa unità di valore. Se può essere sviluppato, verificato e rilasciato indipendentemente, va inserito in una milestone separata.
